## 验收标准

1. **范围澄清**：本期以**顶栏全局搜索**（`AppHeader` → `SearchView` → `musicStore.searchMusic`）为准；本地音乐页当前**无**独立搜索框，**不强制**新增。  
2. 顶栏走 S2.1 新逻辑；placeholder 可提示支持拼音/声母（中英文）。  
3. 搜索历史不被异常污染（对齐高级搜索防污染）。  
4. 若存在其它直接调用 `searchMusic` 的入口，一并受益，无需重复造轮子。  
5. `npm run build` + CHANGELOG。
