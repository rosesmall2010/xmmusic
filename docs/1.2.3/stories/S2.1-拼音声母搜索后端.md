# S2.1 拼音 / 声母搜索后端

**Epic**: 2 — 拼音搜索  
**优先级**: P0  
**状态**: todo  
**依赖**: 无  
**估算**: 2～3 天（含方案 A 回填则取上限）  

---

## 用户故事

作为用户，我输入全拼或声母时，应能搜到对应中文歌名/歌手/专辑。

---

## 验收标准

1. **动手前锁定方案**并写入本 Story「实现记录」：  
   - **A**：DB 预计算列/旁路表 + 存量回填；或  
   - **B**：内存索引 + 曲库变更刷新。  
2. `searchMusic`（或等价）支持汉字、全拼、声母；大小写不敏感；子串命中。  
3. 字段至少 title / artist / album（及现有 file_name）。  
4. **FTS 分流**：拼音/声母查询**不得**直接作为 FTS5 `MATCH` 表达式；与原文 FTS/LIKE 结果合并去重。  
5. 含 FTS 特殊字符的 query 不抛未捕获异常。  
6. 万级库体感可接受；方案 A 须完成存量回填或可后台回填并在回填前有可用降级。  
7. `npm run build` + CHANGELOG。
