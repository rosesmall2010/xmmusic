## 用户故事

作为用户，我只在 XMMusic 窗口前台时用快捷键控制播放；不影响其他软件。

---

## 验收标准

1. **不注册** `globalShortcut`；注释改为「产品决策：仅应用内，禁止改为 true 除非产品变更」。  
2. **主窗口**聚焦默认动作均可用：  
   - 播放/暂停（推荐 **Space**；输入聚焦时除外）  
   - 上一首 / 下一首（普通组合键，不依赖 Media* 作为唯一绑定）  
   - 音量加 / 音量减——**必须在 `App.vue`（或共享 handler）补齐**，现状无 `volume-up`/`volume-down` 分支  
   - 收藏  
3. **迷你播放器**聚焦：至少播停、上下首；音量/收藏尽量支持。  
4. 输入框 / textarea / contenteditable 聚焦时：字母类与 Space 播停不触发。  
5. 默认绑定**不以**系统媒体键为唯一方案（应用内常收不到 MediaPlayPause 等）。  
6. 动作清单**不含** `toggle-window`（避免死键）；历史配置可忽略该键。  
7. `npm run build` + CHANGELOG。

## 实现要点

- composable 或 `before-input-event`；主窗与迷你共用配置。  
- 音量：接到 `playerStore` / 现有音量 API（参考 PlayerBar）。
