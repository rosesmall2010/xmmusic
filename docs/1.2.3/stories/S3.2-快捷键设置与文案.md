# S3.2 快捷键设置与文案

**Epic**: 3 — 应用内快捷键  
**优先级**: P1  
**状态**: todo  
**依赖**: S3.1  
**估算**: 0.5～1 天  

---

## 用户故事

作为用户，我希望在设置里查看/修改**应用内**快捷键，并清楚它们不会在后台抢键。

---

## 验收标准

1. 设置页「快捷键」区块：列出 S3.1 已实现动作与绑定；可改、可恢复默认。  
2. 冲突检测；保存失败有提示；保存后热更新。  
3. 文案一律「应用内快捷键」，禁止「全局快捷键」。  
4. **隐藏或禁用**未实现项（如历史 `toggle-window`），不展示死键。  
5. 配置持久化 `shortcuts`；主窗与迷你共用。  
6. `npm run build` + CHANGELOG。  

---

## 实现要点

- 复用已有 IPC：`get-shortcut-config` / `save-shortcut-config` / `get-default-shortcuts`。  
- 默认表去掉或停用 Media* 唯一绑定，与 S3.1 默认一致。

## 测试建议

- 改键立即生效；恢复默认。  
- UI 无「全局」、无死键项。
