---

## 用户故事

作为用户，我希望在与「匹配歌词」相同的入口匹配/更换单曲封面：列表右键自动匹配，全屏多候选选择；有有效封面时重新匹配需确认。

---

## 验收标准

1. **列表右键**（`SongList.vue`，与歌词匹配同开关）：  
   - 无有效封面 →「匹配封面」→ 调用自动 `match-cover`（≥75），**不弹候选**（对齐歌词右键）。  
   - 有有效封面 →「重新匹配封面」→ confirm 后 `force: true` 自动匹配。  
2. **全屏播放页**（`NowPlayingView.vue`）：与「在线匹配歌词」同级；走**候选列表**（不设相似度下限；无论几条都弹窗预览；可另选本地图片；无在线结果也可打开弹窗仅用本地图），点选后 `apply-cover-candidate` / `apply-local-cover`。控制栏按钮 + 歌词区右键菜单均提供入口。  
3. 成功后刷新列表项；若为当前曲，播放栏/全屏/迷你封面立即更新。  
4. 非 MP3：提示已更新应用内封面、文件未修改。  
5. 匹配中防重复点击；失败展示可区分原因。  
6. i18n `zh.json` / `en.json`。  
7. `npm run build` + CHANGELOG。  

---

## 实现要点

- 右键对齐 `handleMatchLyrics` / `handleRematchLyrics`（自动，非弹窗）：`matchCover` / `matchCover(..., { force: true })`。  
- 全屏对齐歌词候选弹窗；可新建 `CoverMatchSelectModal.vue`（需展示缩略图）；应用时 `applyCoverCandidate(id, songId, { coverUrl, force })`，有有效封面更换须 `force: true`。  
- 「有效封面」与 S1.1 判定一致（路径存在且可读）。

## 非目标
