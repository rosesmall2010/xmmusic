## 1. 界面总览

主窗口由四块组成：

| 区域 | 内容 |
|------|------|
| **左侧边栏** | 「智能推荐」「本地音乐」；「我的音乐」分组下的「我的收藏」「最近播放」（右侧显示数量）；「我的歌单」分组列出全部歌单（显示封面和歌曲数）；底部固定显示本地曲库总数 |
| **顶栏** | 搜索框；右侧依次是迷你模式、浅色/深色切换、中英文切换、设置；Windows / Linux 下还有最小化、最大化、关闭按钮（macOS 使用系统红绿灯） |
| **主内容区** | 当前页面（默认进入「本地音乐」） |
| **底部播放栏** | 当前歌曲、播放控制、进度、收藏、均衡器、定位当前、音量 |

侧边栏「我的歌单」标题旁的「+」会跳到歌单页，在那里新建歌单。

## 2. 建立曲库

### 2.1 设置扫描目录

本地音乐页工具栏点 **「设置扫描目录」**（也可以在设置页的「音乐目录」分区管理）：

- **添加目录**：手动输入路径或点「浏览」选择，最多 **20 个**；重复路径会提示
- 每个目录可以单独 **启用 / 禁用**、**编辑路径**、**删除**
- 删除只会把目录移出扫描列表，**不会删除磁盘上的音乐文件**；设置页删除时还会额外询问是否同时删除该目录已扫描进库的记录
- 对话框里可以直接点 **「扫描」**，立即扫描所有已启用的目录

没有配置任何目录时，「设置扫描目录」按钮会高亮提示。

### 2.2 扫描

- 本地音乐页点 **「扫描」**（没有已启用目录时禁用），或在设置页点「重新扫描所有目录」
- 扫描时会读取歌名、歌手、专辑、年份、流派、时长、码率、采样率、声道等信息，并提取内嵌封面
- 进度条显示当前文件名、已处理数 / 总数和百分比
- **支持入库的格式**：`.mp3` `.flac` `.aac` `.wav` `.ogg` `.m4a` `.ape` `.wma`
- 扩展名与真实格式不符的文件（例如 FLAC 被命名成 `.mp3`）会按文件内容识别，照常入库和播放
- 读取卡住的文件（掉线的网络盘、未下载的网盘占位文件等）单个最多等待 120 秒后跳过，不会让扫描永远停在最后一首；扫描结束会提示有几个文件处理失败
- 重新扫描时，你在应用里手动改过的歌名 / 歌手不会被覆盖

### 2.3 大曲库加载

- 本地音乐首屏先显示 100 首，其余在后台继续加载，页面顶部显示「后台加载中 x / 总数（百分比）」，加载完自动消失
- 列表使用虚拟滚动，几万首歌滚动依然流畅

### 2.4 清理失效记录

本地音乐页工具栏 **「清理失效记录」** 会删除两类记录：

1. 文件已不在磁盘上的（物理丢失）
2. 标记为感叹号、无法识别或播放的

同时会同步清理歌单、收藏、最近播放、播放队列、智能推荐里的对应条目，并重算歌单统计。扫描根目录不可达（外置盘、网络盘未挂载）或无权限访问时会跳过，不会误删。完成后弹窗汇报各项数量。

### 2.5 清除所有

本地音乐页工具栏 **「清除所有」** 会清空曲目、歌单、收藏、播放记录、播放队列等全部数据，**保留**主题、语言、音效等设置和已添加的扫描目录。此操作不可恢复，执行前会二次确认。

> 扫描、批量匹配歌词、批量匹配封面、清理失效记录、单曲手动匹配之间互斥，任一项进行中时其他按钮会禁用并给出提示。

## 3. 浏览与播放

### 3.1 歌曲列表

本地音乐、搜索结果、我的收藏、最近播放、歌单详情使用同一种歌曲列表，各列为：

| 列 | 内容 |
|----|------|
| 序号 | 正在播放的歌曲显示喇叭图标 |
| 标题 | 封面缩略图、歌名、歌手 |
| 专辑 | 专辑名 |
| 文件名 | 磁盘上的文件名，方便识别标签不准的歌 |
| 时长 | 时长、声道、码率、采样率 |
| 操作 | 收藏（心形）、加入 / 移出播放队列 |

**状态图标**（显示在歌名旁）：

- 🟥 **红色文件图标**：文件已不存在
- ⚠️ **黄色感叹号**：无法播放，鼠标悬停可看原因

**双击** 一首歌即开始播放。列表滚动到底部时自动加载更多。列表不支持点表头排序。

### 3.2 播放控制（底部播放栏）

- **左侧**：封面、歌名、歌手。**点击这一块进入全屏播放页**
- **中间**：上一首、播放 / 暂停、下一首、播放模式、播放队列；下方进度条可点击跳转，两端显示当前时间和总时长
- **右侧**：
  - **收藏**当前歌曲
  - **均衡器**（见 [第 16 节](#16-均衡器)）
  - **定位当前**：跳到本地音乐页并把正在播放的歌曲滚动到列表中间；当前歌曲不在本地列表时禁用
  - **音量**：点图标静音 / 恢复（恢复到 80），鼠标悬停时出现音量滑块

### 3.3 播放模式

点播放栏的模式按钮，按以下顺序循环切换：

| 模式 | 规则 |
|------|------|
| 列表顺序 | 播到最后一首停止；在第一首点上一首不动 |
| 随机播放 | 随机选一首，避开当前这首 |
| 列表循环 | 最后一首之后回到第一首，第一首点上一首跳到最后一首 |
| 单曲循环 | 自动播完和手动切歌都重播当前这首 |

手动点上一首 / 下一首与自动切歌遵循同一套规则。

### 3.4 播放引擎与失败处理

- 优先使用系统原生音频播放，失败时自动改用 Howler.js 再试
- 两种方式都放不出来时，这首歌会被标上 ⚠️ 感叹号，1 秒后自动跳到下一首（队列只有一首时停止）；以后这首歌成功播放时会自动去掉标记
- APE、WMA 能扫描入库，但取决于系统解码能力，可能无法播放

### 3.5 播放全部

本地音乐、我的收藏、最近播放、歌单详情页都有 **「播放全部」**，把当前列表全部放入播放队列并从第一首开始。

## 4. 播放队列

点播放栏的 **播放队列** 按钮，从右侧滑出队列抽屉：

- 标题显示队列歌曲数
- 每行显示序号（当前播放显示喇叭）、歌名、歌手 · 文件名、时长
- **双击** 播放该曲；悬停出现 **「×」** 可移出队列
- **「清空队列」**（需确认）
- 打开抽屉或切歌时自动滚动到当前歌曲；即使是上万首的队列，随机切歌也是瞬时定位

歌曲列表「操作」列的按钮、右键菜单、批量操作都可以把歌加入队列。

## 5. 搜索

### 5.1 顶栏搜索框

- 支持按 **歌名、歌手、专辑** 搜索
- 支持 **拼音**：输入全拼（如 `zhoujielun`）或声母（如 `zjl`）都能搜到中文歌名 / 歌手
- **搜索历史**：搜索框为空且获得焦点时显示最近的搜索记录，可一键清空（设置页也能清除）
- **搜索建议**：输入至少 2 个字后，停顿片刻会出现最多 5 条建议
- 键盘操作：上下方向键选择，回车确认，Esc 关闭下拉

### 5.2 搜索结果页

按回车进入搜索结果页，显示关键词和结果数量，**结果一次全部列出**（不限条数）。结果列表与本地音乐列表用法相同，双击播放这一首，右键菜单可用。

## 6. 智能推荐、我的收藏、最近播放

### 6.1 智能推荐

侧边栏 **「智能推荐」** 页包含：

- 四张入口卡片：最近播放（数量）、我的收藏（数量）、本地音乐（总数）、**随机播放**
- **随机播放**：把全部本地歌曲打乱后开始播放，并切换到随机模式（曲库为空时禁用）
- **最近添加**：最新入库的 10 首歌，双击播放

### 6.2 我的收藏

- 在歌曲列表点心形、右键「收藏」、播放栏或全屏页的收藏按钮、快捷键都可以收藏
- 页面提供「播放全部」和「清空」（需确认）

### 6.3 最近播放

- 每开始播放一首歌就记录一次；同一首歌只保留一条，再次播放会移到最前；最多保留 1000 条
- 页面提供「播放全部」；需要清空时到 **设置 → 数据管理 → 清除播放历史**

## 7. 歌单

### 7.1 歌单列表页

- **新建歌单**：只需填写名称
- 歌单以卡片显示封面和歌曲数，点击进入详情
- **拖拽卡片调整顺序**，顺序会保存，侧边栏同步更新

### 7.2 歌单详情页

头部显示封面、名称、歌曲数、创建日期，以及以下按钮：

| 按钮 | 说明 |
|------|------|
| 播放全部 | 空歌单时禁用 |
| 设置封面 | 三种方式：选择本地图片；从歌单内歌曲的封面中挑（每页 100 张，可翻页）；使用应用默认封面 |
| 复制到目录 | 把歌单内全部歌曲按原文件名复制到所选文件夹，同名覆盖；弹窗显示进度和成功 / 失败数。适合导出到 U 盘、备份或分享 |
| 清空 | 移除歌单内所有歌曲（需确认） |
| 编辑 | 重命名歌单 |
| 删除 | 删除歌单（需确认），删除后返回歌单列表 |

歌单内的歌曲列表滚动时分页加载；右键或批量操作可 **「从歌单移除」**。

### 7.3 把歌加入歌单

- **右键「添加到歌单」**：鼠标悬停展开二级菜单，列出 **最近用过的 10 个歌单**，点一下直接加入；底部一项打开完整的选择对话框
- **选择对话框**：列出全部歌单，点击加入；底部可「+ 新建歌单」
- 结果用约 2 秒自动消失的轻提示反馈；歌曲已在歌单中时会提示「已存在」
- 批量加入时显示进度，完成后汇报成功和跳过的数量

- 歌单详情页额外有 **「批量删除」**，作用是从歌单移除
- 点「取消」退出批量模式

## 9. 歌词

### 9.1 歌词从哪里来

播放时按以下顺序查找歌词：

1. 数据库里记录的歌词文件路径
2. 歌曲 **同目录、同名的 `.lrc` 文件**（文件名大小写、中文编码方式不同也能找到），找到后自动记入数据库

所以你自己放在音乐文件旁边的同名 `.lrc` 不需要任何操作就能显示，批量匹配时也不会被当成“无歌词”重新下载。

### 9.2 批量匹配歌词

本地音乐页工具栏 **「批量匹配歌词」**：

- 对曲库中所有没有歌词的歌曲在线搜索，下载后保存为歌曲 **同目录的同名 `.lrc`**
- **四个歌词源同时搜索**：LRCLIB、网易云、酷狗、QQ 音乐，按歌名、歌手相似度自动选最佳结果（歌名相似度需 ≥50；已知歌手时歌手相似度也需 ≥50），只采用带时间轴的歌词
- 歌曲没有歌手标签时，会先清洗文件名（去掉曲目编号、拆开「歌名-歌手」）再搜索，减少搜错
- 识别为纯音乐的歌曲会跳过
- **并发数**在 设置 → 批量匹配 → 歌词批量并发 中设置（1–10）
- **进度面板**：已处理数 / 总数、成功数和成功率、已耗时、预计剩余、进度条，以及每个并发任务的状态（匹配中 / 成功 / 失败 / 跳过 / 空闲）和失败原因
- 点 **「取消」** 立即停止，正在进行的网络请求也会中断
- 结束后弹窗汇报成功、跳过、失败数

### 9.3 单曲匹配歌词

- 列表右键 **「匹配歌词」**（已有歌词时为「重新匹配歌词」，会先确认覆盖）
- 全屏播放页控制栏的 **匹配歌词** 按钮，或歌词区右键 **「匹配歌词」**
- 先显示「正在拉取歌词候选」（可取消），再弹出候选列表：每条标注来源（LRCLIB / 网易云 / 酷狗 / QQ 音乐）和相似度，点选后在下方 **预览歌词全文**，满意再点「使用选中项」
- 单曲候选不设相似度下限，方便你自己挑
- 在线没有找到时，如果同目录有可用的 `.lrc` 会直接关联

### 9.4 选择本地歌词

列表右键或全屏歌词区右键 **「选择本地歌词...」**，可选 `.lrc` 或 `.txt` 文件。软件会把它整理成歌曲同目录的同名 `.lrc`；歌曲所在目录不可写时，直接关联原文件。

### 9.5 歌词显示与校准

- 全屏播放页右侧显示歌词，当前句高亮并自动滚动；**点击任意一句歌词可跳到该时间点**
- **偏移校准**：全屏歌词区右键选择「前进 / 后退 0.5 / 1 / 2 秒」，实时生效；「重置」恢复为 0。偏移范围 ±30 秒，**按每首歌单独保存**，全屏、迷你、桌面歌词同步生效
- **显示歌词时间**：歌词区右键切换，每句歌词前显示精确到 0.1 秒的时间戳，便于核对校准效果
- 没有歌词时，校准相关菜单项禁用，「匹配歌词」仍可使用

## 10. 封面

### 10.1 封面来源

- 扫描时自动提取文件内嵌的封面
- 在线匹配或手动选择的封面

### 10.2 批量匹配封面

本地音乐页工具栏 **「批量匹配封面」**（没有缺封面的歌曲时禁用）：

- 对所有没有有效封面的歌曲在线找图（网易云 / 酷狗 / QQ 三源并发）；先按标签歌名匹配，再按歌手匹配，最后用文件名推测再试（相似度均需 ≥50），仍找不到则放弃
- **并发数** 在 设置 → 批量匹配 → 封面批量并发 中单独设置（1–10）
- 进度面板与批量歌词相同，可随时取消
- 结束后汇报成功（其中写入文件多少首、仅更新应用内多少首）、跳过、失败数
- 与批量匹配歌词不能同时进行

### 10.3 单曲匹配封面

- 列表右键 **「匹配封面」**（已有封面时为「重新匹配封面」，会先确认覆盖）
- 全屏播放页控制栏的 **匹配封面** 按钮，或歌词区右键 **「匹配封面」**
- 先显示「正在拉取封面候选」，再弹出候选封面（网易云 / 酷狗 / QQ，带来源标记），选中后可预览大图，点「使用选中封面」应用
- 候选框里也可以点 **「选择本地图片」**；在线找不到时同样可用本地图片

### 10.4 选择本地封面

列表右键或全屏歌词区右键 **「选择本地封面...」**，直接选一张图片（jpg / png / gif / bmp / webp）作为这首歌的封面。

### 10.5 封面写到哪里

- **MP3**：封面写入文件的 ID3 标签，用其他播放器打开也能看到
- **其他格式**：只更新应用内显示的封面，原文件不修改
- WebP 图片会自动转为 JPEG，避免其他播放器不认
- 写标签在后台线程执行，并采用“先写临时文件再替换”的方式，中途中断也不会把文件写坏

### 10.6 导出封面

列表右键（本地音乐页）或全屏歌词区右键 **「导出封面」**：

- 弹出保存对话框，默认文件名为「歌手 - 标题」，扩展名按图片真实格式确定
- 对话框 **默认打开上次导出的文件夹**；第一次使用（或该文件夹已不存在）时打开当前用户的「下载」文件夹
- 歌曲没有封面时该菜单项置灰
- 导出成功后提示保存路径

## 11. 标签编辑与同步到数据库

### 11.1 打开标签编辑

歌曲列表右键 **「编辑标签」**，或全屏播放队列右键「编辑标签」。

### 11.2 三栏对比编辑

可编辑字段：**歌手、歌名、专辑、年份、流派**。每个字段三栏并排：

| 栏 | 含义 |
|----|------|
| 数据库 | 应用里当前显示的值 |
| 当前 ID3 | 文件里原始的标签值（可能是乱码） |
| 编辑后 | 你最终要保存的值，可以直接手动修改 |

**每个字段的按钮**：

- **自动识别编码**（推荐）：自动识别 UTF-8、GB18030、Big5，以及被错存为 Latin1 的乱码并还原，填入「编辑后」
- **GBK 转码**：自动识别不准时手动按 GBK 转换
- **复制 ID3** / **复制数据库**：把对应栏的值填入「编辑后」

**整体按钮**：全部自动识别编码、全部按 GBK 转码、全部复制 ID3、全部复制数据库、**对调歌手歌名**、**按文件名推测**、**重置**。这些都只改「编辑后」一栏。

**保存方式**：

- **保存**：MP3 写回文件标签并同步数据库；其他格式只更新数据库（会有提示）
- **仅同步数据库**（仅 MP3 显示）：只改应用里的显示，不动文件
- 没有改动时保存按钮不可点；点弹窗外部不会关闭，避免误操作丢失内容

### 11.3 同步到数据库

列表显示乱码、但文件本身标签正确时，可以只更新数据库：

- 单曲：在标签编辑里点「仅同步数据库」
- 批量：进入批量操作，选中歌曲后点 **「同步到数据库」**，按文件名或 ID3 解析出的信息写入数据库，**不修改文件**；英文标签不会被误转码；完成后汇报更新数、无需变更数、失败数

## 12. 歌曲详情

右键 **「查看详情」** 打开详情弹窗，分三组：

- **歌曲信息**：标题、歌手、专辑、时长、是否有歌词
- **音频信息**：码率、采样率、声道、编码格式、比特率模式（CBR / VBR）及编码配置
- **文件信息**：文件类型、文件名、完整路径、文件路径 MD5、文件大小

底部 **「复制详细信息」** 可把全部信息以文本复制到剪贴板。

## 13. 全屏播放页

点击底部播放栏左侧的封面 / 歌名区域进入。

### 13.1 顶栏

从左到右：返回、切换到迷你模式、浅色 / 深色切换、切换语言、**切换特效**、**特效开关**、**桌面歌词**、**显示播放队列**（Windows / Linux 还有窗口控制按钮）。

### 13.2 六套视觉特效

点「切换特效」按顺序循环，选择会被记住：

| 特效 | 说明 |
|------|------|
| 霓虹频谱 | 音乐律动实时可视化 |
| 火焰 | 蓝色火焰按频段跳动，贴合鼓点和低音 |
| 闪电 | 音乐突增时炸开折线电光 |
| 经典唱片 | 密纹黑胶与唱臂 |
| CD | 光盘转动光影 |
| 磁带 | 实体磁带，贴纸区铺满专辑封面 |

**特效开关** 可以单独关闭频谱、火焰、闪电的背景动画；唱片、CD、磁带模式下该按钮置灰。

页面背景会从封面提取主色，深色主题下压暗、浅色主题下提亮，与主题保持协调。

### 13.3 控制栏

进度条，以及：收藏、上一首、播放 / 暂停、下一首、播放模式、均衡器、**匹配歌词**、**匹配封面**、静音、音量滑块。歌词与封面匹配进行中时，两个匹配按钮互相禁用。

### 13.4 右侧面板：歌词 / 队列

右侧在「歌词」与「播放队列」之间切换（顶栏按钮或面板标签）。

**歌词区右键菜单**（按顺序）：

1. 前进 0.5 秒 / 后退 0.5 秒 / 前进 1 秒 / 后退 1 秒 / 前进 2 秒 / 后退 2 秒
2. 重置
3. 添加到歌单（二级菜单）
4. 匹配歌词、匹配封面、导出封面、选择本地歌词...、选择本地封面...
5. 显示歌词时间 / 隐藏歌词时间

**队列区**：双击播放，「×」移出队列。右键菜单：播放、收藏 / 取消收藏、添加到歌单、编辑标签、在文件管理器中打开、查看详情、从播放队列移除。

## 14. 迷你模式

从顶栏或全屏页顶栏的 **迷你模式** 按钮进入：

- 主窗口缩小为 320×480 的小窗，**始终置顶**，可拖动顶部区域移动
- 显示封面、歌名、歌手、当前一句歌词和进度条（可点击跳转）
- 底部按钮：上一首、播放 / 暂停、下一首
- 顶部按钮：**切换封面样式**（无特效 → 唱片 → CD → 磁带 循环）、浅色 / 深色切换、退出迷你模式
- **与全屏特效双向同步**：进入迷你时，全屏是唱片 / CD / 磁带则沿用同一样式，是频谱类则显示无特效；在迷你里切换的样式退出时会写回全屏
- 退出后窗口恢复到进入前的大小、位置和页面

## 15. 桌面歌词

在全屏播放页顶栏点 **「桌面歌词」** 打开或关闭：

- 一个透明的独立小窗，显示当前一句歌词（白字黑描边），没有歌词时显示「暂无歌词」；始终置顶，不占任务栏
- 系统级毛玻璃背景（macOS / Windows）
- 未锁定时可拖动顶部控制条移动位置，控制条上有「锁定」和关闭按钮
- **锁定** 后鼠标点击直接穿透窗口，不影响操作下面的软件，同时隐藏控制条
- 解除锁定：回到全屏播放页再点一次「桌面歌词」关闭，重新打开即为未锁定状态
- 歌词偏移校准同步生效

## 16. 均衡器

底部播放栏或全屏控制栏的 **均衡器** 按钮打开面板：

- **总开关**
- **预设**：平坦、流行、摇滚、爵士、古典、重低音、高音增强、人声增强；关闭状态下选预设会自动开启；手动调整后显示为「自定义」
- **10 个频段**：31、62、125、250、500 Hz，1K、2K、4K、8K、16K Hz，每段 −12 ~ +12 dB，步进 0.5 dB
- **重置**：恢复平坦
- 普通播放、迷你模式、全屏播放 **共用同一套音效**，切换界面不会丢失；设置会被记住

## 18. 快捷键

在 **设置 → 应用内快捷键** 查看和修改。快捷键 **只在 XM Music 窗口处于前台时生效**（主窗口和迷你模式都可用），不会影响其他软件；光标在输入框里时，空格等单键不会触发。

| 功能 | macOS 默认 | Windows / Linux 默认 |
|------|-----------|---------------------|
| 播放 / 暂停 | `Space` | `Space` |
| 上一首 | `⌘ + ←` | `Ctrl + ←` |
| 下一首 | `⌘ + →` | `Ctrl + →` |
| 音量加（+5） | `⌘ + Shift + ↑` | `Ctrl + Shift + ↑` |
| 音量减（−5） | `⌘ + Shift + ↓` | `Ctrl + Shift + ↓` |
| 收藏当前歌曲 | `⌘ + Shift + F` | `Ctrl + Shift + F` |

**修改方法**：点击某个动作的按键框，按下新的组合键即可；按 Esc 取消录制。与其他动作冲突时会提示并要求换一个。每项可单独「清除」，底部「恢复默认」可一键还原（需确认）。

## 21. 启动与状态记忆

- 启动后默认进入 **本地音乐** 页
- **会记住**：播放队列、当前歌曲、播放模式、音量、均衡器、主题、语言、全屏特效、迷你封面样式、最近导出封面的文件夹
- 启动时会自动剔除队列中已不在曲库的歌曲
- **不记住播放进度**：重新打开后从歌曲开头开始，且不会自动开始播放
- **只允许运行一个实例**：再次打开应用会把已有窗口调到前面（最小化时自动还原）

## 22. 数据存放位置

曲库数据库、设置和封面缓存保存在应用数据目录中，与音乐文件本身无关：

| 平台 | 路径 |
|------|------|
| macOS | `~/Library/Application Support/xmmusic/` |
| Windows | `%APPDATA%\xmmusic\` |
| Linux | `~/.config/xmmusic/` |

目录中常见内容：

- 曲库数据库（`.db` 文件）
- `covers/`：封面缓存
- `id3_backups/`：ID3 修复前的备份

在线匹配下载的歌词保存在 **歌曲所在目录**（同名 `.lrc`），不在应用数据目录中。

开发模式（`npm run dev`）使用独立的 `xmmusic-dev` 目录，不会影响正式版数据。

## 23. 已知限制

以下是当前版本中已知的问题或尚未完成的功能：

| 项目 | 现状 |
|------|------|
| 设置 → 关闭主面板 | 开关暂未生效，点击窗口关闭按钮总是直接退出应用 |
| 设置 → 自动播放 | 开关暂未生效，启动时不会自动播放 |
| 设置 → 检查更新 | 尚未接入真实的版本检查，请到 [GitHub Releases](https://github.com/rosesmall2010/xmmusic/releases) 查看新版本 |
| 设置 → 清除缓存 | 只清除浏览器层面的缓存，不会删除封面缓存 |
| 桌面歌词锁定 | 锁定后窗口内没有解锁按钮，需要在全屏页关闭后重新打开 |
| 桌面歌词入口 | 只能从全屏播放页打开 |
| 均衡器 | 不能保存自定义预设 |
| 歌曲列表 | 不支持点表头排序 |
| 迷你模式 | 没有音量控制，窗口大小固定 |
| 窗口大小 | 不记忆主窗口的大小和位置 |
| APE / WMA | 能入库，但可能无法播放（无法播放时会自动跳过） |
| 写入文件标签 | 仅支持 MP3，其他格式的标签和封面修改只保存在应用内 |

完整版本变更记录见 [CHANGELOG.md](../CHANGELOG.md)。
